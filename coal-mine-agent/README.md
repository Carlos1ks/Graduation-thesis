# coal-mine-agent — 前端说明

本目录是煤矿应急救援决策 AI 智能体的 **React + Vite 前端**。

## 本地启动

```bash
# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev
```

访问 [http://localhost:5173](http://localhost:5173)

## 完整运行指南

请参阅根目录的 [README.md](../README.md)，其中包含：
- 环境要求
- API 密钥配置（Longcat / 百度 AI）
- 后端启动步骤
- 常见问题排查

## 构建生产包

```bash
npm run build
```

产物输出到 `dist/` 目录。
